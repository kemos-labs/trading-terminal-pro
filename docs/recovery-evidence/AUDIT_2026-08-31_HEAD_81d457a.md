## Blocking findings

### P0 — SERFF product semantics are wrong

- `services/rates-worker/services/rate_risk.py:1250-1288` creates four-leg SR3 calendar-of-calendars and assigns `kind: "serff"` plus names `SERFF 4-leg ...`.
- `services/rates-worker/services/rate_risk.py:1333-1381` assigns SERFF names to SR3/SR1 implied-rate minus cash EFFR proxies.
- `services/rates-worker/services/rate_risk.py:1415-1428` describes `SR3-ZQ` as true SERFF.
- `src/components/macrovol/rates/SerffBoard.test.tsx:18-33` locks the wrong four-leg behavior into tests.

Correct authority: CME SERFF is same-month `SR1-ZQ`, ratio `1:1`. Four-leg SR3 structures are curve/calendar tools. Cash EFFR substitutions are derived proxies, not listed SERFF.

### P0 — fabricated empty-curve rate

- `services/rates-worker/services/rate_risk.py:382-390` returns `0.04` when no curve exists.
- `/api/rates/term-structure` can expose that as a treasury-curve result.

Missing curve must be null/unavailable and carry coverage/warning metadata.

### P0 — SR3 weekend/holiday compounding formula

- `services/rates-worker/services/stir.py:98-133` repeats the most recent fixing for each calendar date and multiplies daily factors.
- CME settlement uses each fixing with its publication interval/day count `n_i`: `1 + r_i*n_i/360`.

Add independent golden weekend/holiday/quarter-boundary vectors before promotion.

### P0 — route parity ignores HTTP method

- `scripts/route-parity.mjs:59-67` reduces runtime authority to path patterns.
- `scripts/route-parity.mjs:143-163` records/checks only paths.

A frontend POST to a GET-only route can pass. The gate must match method plus path.

- OpenAPI declares enums/ranges, so runtime and contract behavior diverge.

Use shared Fastify request schemas and typed 400 errors.
